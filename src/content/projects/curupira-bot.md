## Sobre o Projeto

**Curupira Agentic Bot** é um assistente agêntico para computadores de placa única (Raspberry Pi). Focado em interatividade proativa e execução autônoma de tarefas em ambientes com hardware limitado.

Um experimento de IA que cabe literalmente na palma da mão.

## Stack Técnico

- Python 3.x
- Claude API (otimizado para edge)
- Raspberry Pi 4
- GPIO control
- Voice recognition

## Características

- Execução autônoma de tarefas
- Baixo consumo de recursos
- Interação proativa com o ambiente
- Totalmente open source
