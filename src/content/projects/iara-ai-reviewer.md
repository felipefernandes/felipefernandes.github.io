## Sobre o Projeto

**Iara AI Code Reviewer** é um agente Python open source para análise estática automatizada de Pull/Merge Requests. Integrado com as APIs do GitHub e GitLab, é compatível com Claude, Gemini e GPT.

Nasceu da necessidade real de escalar revisões de código sem aumentar a carga cognitiva do time.

## Stack Técnico

- Python 3.x
- Claude / GPT-4 / Gemini APIs
- GitHub / GitLab REST APIs
- Análise semântica de código

## Impacto

Redução de 60% no tempo médio de revisão de código, permitindo que desenvolvedores foquem em problemas complexos enquanto o agente cuida de validações automáticas e sugestões de melhoria.
