## Sobre o Projeto

**Job Fit Analyzer** é uma ferramenta web open-source projetada para analisar e avaliar o nível de compatibilidade (*fit*) entre o currículo de um candidato e a descrição de uma vaga de emprego específica.

O projeto nasceu para empoderar profissionais a ajustarem seus currículos de forma inteligente para sistemas de triagem (ATS) e entenderem quais requisitos de uma vaga lhes faltam, fornecendo insights detalhados e sugestões práticas de aprimoramento.

## Stack Técnico

- Python 3.x
- Streamlit (para interface web rápida e interativa)
- LLMs (Claude & Gemini via API)
- Processamento de Linguagem Natural (NLP) e Parsing de Markdown/Texto

## Funcionalidades e Diferenciais

- **Parsing de Currículos**: Entrada direta via texto livre, Markdown ou links.
- **Análise Multidimensional**: Avalia as competências técnicas (Hard Skills), comportamentais (Soft Skills) e nível de senioridade exigido.
- **Feedback Estruturado**: Fornece uma pontuação percentual de aderência e descreve exatamente onde há lacunas (*gaps*) entre o perfil e a vaga.
- **Recomendações Práticas**: Sugestões de palavras-chave, habilidades a destacar e pontos de melhoria na redação do currículo.

## Impacto

- Projeto open-source que facilita a preparação de candidatos para processos seletivos.
- Interface simples e de fácil execução local ou em nuvem.
