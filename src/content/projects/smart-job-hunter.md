## Sobre o Projeto

**Smart Job Hunter** é um agente pessoal em Python/Vercel que monitora vagas em Gupy e Greenhouse via API, filtra oportunidades com scoring de relevância por LLM e envia notificações pelo Telegram.

Construído por necessidade própria — e que virou referência de como IA pode ser uma extensão prática do cotidiano.

## Stack Técnico

- Python 3.x
- Gupy / Greenhouse APIs
- Claude API (scoring)
- Telegram Bot API
- Vercel (Cron Jobs)

## Funcionalidades

- Monitoramento automático de vagas
- Scoring de relevância por LLM
- Notificações em tempo real
- Filtros personalizados

## Impacto

Redução de 80% no tempo gasto procurando vagas manualmente. O agente cuida da triagem e só notifica sobre oportunidades realmente relevantes.
