## Sobre o Projeto

**Bug Clustering Analysis** é um modelo de análise semântica em Python + Gemini para detectar padrões em reports de bugs do JIRA.

Identifica gargalos sistêmicos de qualidade antes que eles virem incidentes — e comunica isso de forma visual para stakeholders não-técnicos.

## Stack Técnico

- Python 3.x
- Gemini API
- JIRA REST API
- Análise semântica
- Visualização de dados

## Resultado

Desenvolvido para **Gazeus Games**, o sistema identificou padrões críticos que levaram a melhorias estruturais no processo de QA, reduzindo bugs recorrentes em 45%.

## Impacto

- 45% redução em bugs recorrentes
- Detecção precoce de problemas sistêmicos
- Visualizações claras para stakeholders não-técnicos
