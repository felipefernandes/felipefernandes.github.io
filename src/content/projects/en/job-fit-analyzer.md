## About the Project

**Job Fit Analyzer** is an open-source web tool designed to analyze and evaluate the compatibility (*fit*) between a candidate's resume and a specific job posting description.

The project was created to empower professionals to intelligently adapt their resumes for applicant tracking systems (ATS) and understand which job requirements they might be missing, providing detailed insights and practical improvement suggestions.

## Technical Stack

- Python 3.x
- Streamlit (for a fast and interactive web interface)
- LLMs (Claude & Gemini via API)
- Natural Language Processing (NLP) and Markdown/Text Parsing

## Features and Differentiators

- **Resume Parsing**: Direct input via plain text, Markdown, or links.
- **Multidimensional Analysis**: Evaluates technical competencies (Hard Skills), behavioral traits (Soft Skills), and required seniority level.
- **Structured Feedback**: Provides a percentage match score and details exactly where there are gaps between the profile and the job post.
- **Practical Recommendations**: Keyword suggestions, skills to highlight, and resume writing improvement points.

## Impact

- Open-source project that simplifies candidate preparation for recruitment processes.
- Simple interface, easily run locally or in the cloud.
