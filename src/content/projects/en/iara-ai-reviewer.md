## About the Project

**Iara AI Code Reviewer** is an open-source Python agent for automated static analysis of Pull/Merge Requests. Integrated with GitHub and GitLab APIs, it supports Claude, Gemini, and GPT.

It was born from a real need to scale code reviews without increasing the team's cognitive load.

## Technical Stack

- Python 3.x
- Claude / GPT-4 / Gemini APIs
- GitHub / GitLab REST APIs
- Semantic code analysis

## Impact

60% reduction in average code review time, allowing developers to focus on complex problems while the agent handles automatic validation and improvement suggestions.
