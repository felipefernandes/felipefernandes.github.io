## About the Project

**Bug Clustering Analysis** is a semantic analysis model built with Python + Gemini to detect patterns in JIRA bug reports.

It identifies systemic quality bottlenecks before they turn into incidents — and communicates them visually to non-technical stakeholders.

## Technical Stack

- Python 3.x
- Gemini API
- JIRA REST API
- Semantic analysis
- Data visualization

## Result

Developed for **Gazeus Games**, the system identified critical patterns that led to structural improvements in the QA process, reducing recurring bugs by 45%.

## Impact

- 45% reduction in recurring bugs
- Early detection of systemic issues
- Clear visualizations for non-technical stakeholders
