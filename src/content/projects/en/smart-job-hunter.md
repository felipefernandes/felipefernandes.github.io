## About the Project

**Smart Job Hunter** is a personal agent built with Python/Vercel that monitors jobs on Gupy and Greenhouse via API, filters opportunities using LLM-based relevance scoring, and sends notifications via Telegram.

Built for personal use — and it became a reference for how AI can be a practical extension of daily life.

## Technical Stack

- Python 3.x
- Gupy / Greenhouse APIs
- Claude API (scoring)
- Telegram Bot API
- Vercel (Cron Jobs)

## Features

- Automatic job monitoring
- LLM-based relevance scoring
- Real-time notifications
- Customized filters

## Impact

80% reduction in time spent manually searching for jobs. The agent handles the screening and only notifies about truly relevant opportunities.
