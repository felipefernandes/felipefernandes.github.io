## About the Project

**Curupira Agentic Bot** is an agentic assistant for single-board computers (Raspberry Pi). Focused on proactive interactivity and autonomous task execution in hardware-constrained environments.

An AI experiment that literally fits in the palm of your hand.

## Technical Stack

- Python 3.x
- Claude API (optimized for edge)
- Raspberry Pi 4
- GPIO control
- Voice recognition

## Features

- Autonomous task execution
- Low resource consumption
- Proactive interaction with the environment
- Fully open source
