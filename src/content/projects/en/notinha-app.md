## About the Project

**Notinha App** is a family application for financial and expense control created in less than 24 hours using **AI-Augmented Software Engineering** techniques.

Developed to solve real home organization problems, the app was designed with a highly intuitive interface and automated features to minimize the friction of daily expense tracking.

## Technical Stack

- Next.js + React
- Firebase (Auth & Firestore)
- Gemini Flash API + n8n (for smart categorization with memory)
- Google Sheets API (for real-time transaction synchronization)
- Tailwind CSS

## Features and Differentiators

- **Automated AI Categorization**: An agent that categorizes and learns the family's categorization preferences.
- **Two-Way Synchronization**: Transactions instantly appear in the Google Sheets spreadsheet.
- **Swipe-to-Navigate**: Optimized mobile interface with gesture navigation for quick transition between months.
- **Multi-Admin Architecture**: Allows shared control among family members.

## Impact

- End-to-end development time in just **24 hours**.
- Zero operational friction: 100% of household entries automatically categorized and consolidated in Google Sheets.
