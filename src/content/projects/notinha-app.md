## Sobre o Projeto

**Notinha App** é um aplicativo familiar para controle financeiro e despesas criado em menos de 24 horas utilizando técnicas de **AI-Augmented Software Engineering**.

Desenvolvido para sanar problemas reais de organização doméstica, o app foi projetado com uma interface altamente intuitiva e recursos automatizados para diminuir ao máximo a fricção do registro diário de gastos.

## Stack Técnico

- Next.js + React
- Firebase (Auth & Firestore)
- Gemini Flash API + n8n (para categorização inteligente com memória)
- Google Sheets API (para sincronização em tempo real das transações)
- Tailwind CSS

## Funcionalidades e Diferenciais

- **Categorização Automática com IA**: Agente que categoriza e aprende a preferência de categorização da família.
- **Sincronização em Duas Vias**: Lançamentos aparecem instantaneamente na planilha do Google Sheets.
- **Swipe-to-Navigate**: Interface móvel otimizada com navegação por gestos para transição rápida entre meses.
- **Arquitetura Multi-Administrador**: Permite controle compartilhado entre os membros da família.

## Impacto

- Tempo de desenvolvimento de ponta a ponta em apenas **24 horas**.
- Zero fricção operacional: 100% dos lançamentos domésticos categorizados automaticamente e consolidados no Google Sheets.
